# Special Elite

Fuente de Astigmatic (Brian J. Bonislawsky y Jim Lyles), distribuida bajo Apache License 2.0; licencia y aviso de copyright en `LICENSE-SpecialElite.txt`.

Archivo latino original, sin modificar, procedente de `@fontsource/special-elite@5.3.0`:
https://registry.npmjs.org/@fontsource/special-elite/-/special-elite-5.3.0.tgz

Se extrajo únicamente el WOFF2 y su licencia; no se ha añadido una dependencia npm ni se ejecutan scripts del paquete. El navegador lo carga desde `/assets/fonts/SpecialElite.woff2`, sin servicios externos. Incluye el alfabeto español. La variante regular se engrosa mediante el peso y el trazo CSS pedidos; Courier queda como fallback.
